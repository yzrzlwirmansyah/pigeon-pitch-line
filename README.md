## The entry

> Investors, we turn sidewalk crumbs into recurring revenue; pigeons call it lunch, your analysts call it seed funding.

**117 characters** (verified with Python: `len(line)` = 117), one line, English.

## The joke

The pitch reframes a pigeon's lunch as a business model: sidewalk crumbs become recurring revenue, and the punchline lands on "seed funding" — birdseed for the pigeons, a seed round for the investors. The pigeons think they're eating; the analysts think they're investing.

## Run it

```sh
python3 main.py
```

This writes the entry line (exactly, with no trailing newline) to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else instead. The script validates the line first and exits non-zero if it is empty, over 200 characters, or contains a line break.
